# XORPAY web dashboard (prototype)

A clickable web prototype of the Unified MSME Payment Platform. It runs entirely in the
browser with sample data. No backend is needed and no real money moves.

**Open it:** download `xorpay-web.html` and double-click it, or open it in any browser.
(`index.html` is the same page without the HTML wrapper, used for hosted previews.)

## Screens
- **Command deck** – monthly payout, card float, upcoming payments, 6-month cash-out chart
- **Pay** – any category (vendor, rent, GST, TDS, salaries, education, utilities), live fee quote
- **Schedules** – recurring/one-time payments, 30-day timeline, pause/resume, run now
- **Vendors** – payee list, add vendor with IFSC/UPI/GSTIN validation and penny-drop verification
- **Transactions** – filter/search ledger, receipts, copy as CSV
- **Reports & GST** – spend by category, top payees, monthly statement, GST-on-fee ITC
- **Plan & billing** – subscription priced by turnover (MSME bands)
- **About XORPAY** – problem, solution, money flow, fund use, milestones

## Pricing model shown
- Subscription by annual turnover: Micro (≤ ₹5 Cr) ₹999/mo · Small (≤ ₹50 Cr) ₹2,999/mo ·
  Medium (≤ ₹250 Cr) ₹7,999/mo · Enterprise custom. Annual = 10× monthly.
- Card convenience fee **2% + 18% GST on the fee, only on credit-card payments**.
  UPI and net banking are free.
